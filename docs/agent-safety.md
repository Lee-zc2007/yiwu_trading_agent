# Agent 安全边界

## 可做

Agent 只能调用注册在 `TOOL_REGISTRY` 的工具：读取外商档案、信用分、最近交易、订单风险、预警列表、客户对比、事件详情和核验清单。每次回复同时返回工具名、参数摘要、数据源 ID 和关联对象 ID。

## 不可做

- 不允许模型直接生成或执行 SQL。
- 不把模型常识当作当前客户事实。
- 不自动修改交易、客户或风险事件。
- 不自动暂停发货、加入黑名单或作最终交易决策。
- 数据不足时必须说明不足，而不是补全不存在的信息。

## LLM 失败策略

只有 `AGENT_MODE=llm` 且存在 API Key 时才请求外部兼容服务。网络错误、无效 JSON、未知工具或工具参数错误都会回退到确定性 Mock Agent；核心风控 API 不依赖 LLM。

## 生产化补充

真实部署需要对提示注入做输入/输出过滤，对外部模型的数据传输取得授权，按字段脱敏，限制速率和预算，记录完整工具调用审计，并对不同角色实施最小权限。
