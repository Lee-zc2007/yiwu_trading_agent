# 验收清单

## 功能

- [x] 外商 CRUD、搜索、筛选、详情与信用历史
- [x] 交易新增、列表、CSV/XLSX 导入、逐行错误
- [x] 确定性信用评分和置信度
- [x] 12 条可配置风险规则与结构化证据
- [x] Isolation Forest 训练、推理、版本与统计降级
- [x] 综合风险分、风险事件、状态/指派/处置与审计
- [x] Mock Agent 和可选 LLM 工具调用模式
- [x] 8 个页面与 6 个一键路演场景

## 工程

- [x] Next.js App Router + TypeScript + Tailwind + TanStack Query + Zustand + ECharts
- [x] FastAPI + Pydantic + SQLAlchemy + Alembic
- [x] PostgreSQL/Redis Docker Compose，本地 SQLite 降级
- [x] Windows、Linux/macOS 启停脚本
- [x] Swagger/ReDoc、示例 CSV、测试和架构文档

最终构建与浏览器实测结果应以交付时的终端记录为准；本文件仅记录功能覆盖关系。
