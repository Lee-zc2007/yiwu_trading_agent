# 5 分钟路演脚本

1. **工作台（40 秒）**：说明 20 个外商、300 笔交易、风险分布和待处理预警均来自可复现虚构数据。
2. **外商详情（50 秒）**：打开任意客户，展示 100 分信用分、五个子维度、置信度、历史曲线与交易记录。
3. **路演场景（70 秒）**：运行“小额试单后突然大额采购”。强调 12 条规则、Isolation Forest 和信用分是并行证据，结果不是欺诈认定。
4. **风险检测结果（50 秒）**：逐条展示命中原因、阈值、历史均值、特征快照、模型和规则版本。
5. **风险预警（45 秒）**：指派“风控专员”，状态改为 investigating。演示黑名单动作在未确认时会被拒绝。
6. **AI 风控助手（55 秒）**：选择对应外商并提问“为什么风险较高？给我核验清单”。展开工具调用与数据来源，说明 Agent 不直连 SQL、不自动决策。
7. **收束（30 秒）**：指出项目可切 PostgreSQL/Redis、可配置兼容 LLM，也可在模型不可用时安全降级，适合继续接真实授权数据。

备用演示：若现场网络不可用，Mock Agent、SQLite 和本地模型均不依赖外网；若模型文件丢失，系统会基于数据库自动训练或使用统计降级。
