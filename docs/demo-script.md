# 路演讲解脚本

## 8分钟完整版

### 0:00—0:50 项目背景：首页

打开“项目首页”。从义乌“莫名其妙、无中生有、点石成金”的发展叙事切入：过去靠见面和熟人建立信任，现在AI生图、翻译和跨境平台显著提高效率，但线上客户到底是谁、能否付款和履约，仍然难判断。

### 0:50—1:30 核心主张：首页

指向“过去—现在—未来”时间轴和全链路流程。强调本项目不是另一个跨境电商平台，而是一套把效率工具与数字信任连接起来的智能体：“AI不仅帮助义乌商户卖得更快，也帮助他们卖得更放心。”

### 1:30—2:10 经营全景：老板驾驶舱

打开“老板驾驶舱”。依次指向今日询盘、预计成交额、AI自动处理率和风险订单。悬停最近7天趋势、来源分布与转化漏斗。明确数据是 Demo 模拟测算，展示的是未来经营指标体系。

### 2:10—2:55 从需求到商品：AI产品设计

打开“AI产品设计”。选择“保温杯、法国、现代简约、海盐蓝”，点击“生成产品方案”。展示产品定位、包装、核心卖点、市场匹配分、预计毛利和交期。强调义乌柔性供应链与市场洞察结合。

### 2:55—3:35 全球展示：3D数字展台

打开“3D数字展台”。拖拽旋转、滚轮缩放并点击一个产品；切换展台主题和语言；点击“AI讲解”和“添加到询盘单”。说明若现场 WebGL 失败，可点击“2D降级演示”，不会黑屏。

### 3:35—4:30 AI接待：销售助手

打开“AI销售助手”，一键加载场景A“法国采购商寻找环保保温杯”。展示AI推荐、购买意向、预计金额与关注点。再加载场景C，指出客户要求货到付款、拒绝公司验证后，风险分升高，系统不再只追求成交速度。

### 4:30—5:10 智能报价：报价中心

打开“智能报价”。调整数量、折扣和贸易术语，观察报价总额、利润和毛利率实时变化。点击保存报价和下载中英文PDF；指出低于15%毛利率会触发护栏。

### 5:10—6:15 数字信任：风险中心

打开“数字信任中心”，选择四个测试客户中的“极高风险疑似诈骗客户”。解释92分由身份验证、付款方式、账户变更、行为一致性等贡献累加而来。展示建议暂停、100%预付款、视频核验和账户二次确认。强调可解释性是本项目区别于普通电商Demo的核心。

### 6:15—7:05 履约与量化：订单、效果量化

快速打开“订单与物流”查看询盘到完成的时间轴，再打开“效果量化”。拖动每日询盘和AI自动处理比例，现场展示节省时间、人工成本、新增成交额、避免风险损失和ROI；说明全部是可调整的假设估算。

### 7:05—8:00 社会价值：调研成果

打开“调研成果”。回到研究问题：数字化提高效率后，如何重建跨境信任？说明占位数据将在真实调研完成后通过独立JSON替换。最后总结三段演化：人际信任 → 数字效率 → AI数字信任。收束口号：“让世界看见义乌好货，也让每一笔跨境交易更放心。”

## 路演失败应急方案

- 后端启动失败：前端会自动显示 `OFFLINE DEMO`，产品、驾驶舱、对话、询盘、订单和主要计算使用内置数据继续演示。PDF按钮会调用浏览器打印作为替代。
- 3D加载失败：页面自动切换2D商品展厅；也可提前点击“2D降级演示”。
- 网络中断：默认 Mock 模式完全不依赖互联网，避免刷新后直接按既定路径演示。
- 真实AI不可用：保持 `.env` 中 `AI_PROVIDER=mock`；即使配置真实接口，调用失败也会自动降级并返回 Mock 结果。
- 浏览器或投影异常：提前在 `docs/screenshots/` 放置首页、驾驶舱、销售助手、风险中心、报价和效果量化截图；建议另录制一段不超过90秒的核心闭环视频。
- 数据被误改：进入“系统设置”点击“重置全部演示数据”，或运行 `python scripts/init_demo_data.py`。
